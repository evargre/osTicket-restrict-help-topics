# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-03-16

### Added

- Per-user help topic allow list stored in `{prefix}user_topic_access`.
- Staff **Help Topics** tab on end user profile.
- Client portal filtering on `open.php` (HTML + JavaScript).
- Backend validation on `ticket.create.before`.
- English UI strings with osTicket `__()` / `/* trans */` markers.
- Hook registration via `init()` when the plugin is active (without requiring an enabled instance).
